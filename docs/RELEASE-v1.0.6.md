# v1.0.6 · Codex 过滤管理（服务 v32）

- 工作台与 Magpie 合并版统一为暖灰/铜色风格，采用历史过滤、模型监测、检测记录、设置与诊断四个分区，更新全部 README 配图。
- 右上角单个月亮/太阳图标切换明暗，记住浏览器选择。
- 模型监测优先使用当前供应商的最近实际请求，再使用检测历史；没有记录时在当前页展开手动选择，配置模型仅作预填。最近请求不代表当前前台会话，上游声明不构成身份认证。
- “调整监测”在当前页展开，实际路由与手动检测选项分别说明；刷新不丢失编辑内容。
- 新增本机运行诊断、关联请求编号、轮转日志和脱敏导出，区分未收到请求、规则直通、无需清理、已过滤及上游故障。导出前可预览，工具不自动上传。

CC Switch 继续通过本地代理过滤；Magpie 继续通过原生中间件过滤，不改写直连 Magpie 的 Codex 地址。新安装默认不启用供应商规则或保护，已有配置保留。过滤与评分算法不变。

Magpie 完整工作台单独从 [原插件仓库 v0.2.0](https://github.com/unisong/magpie-codex-history-filter/releases/tag/v0.2.0) 分发；只需过滤可直接用 Magpie 原生页面，无需打开独立工作台。社区市场版本不会因本次 GitHub 发布自动升级。

## 升级

停止旧过滤服务后，以新发布包中的源码替换原目录的公开文件，保留自己的 `.runtime/` 数据。不要将其他机器的运行配置覆盖到本机；重新双击 `Start.bat` 打开管理页，并核对页面服务版本 v32。Magpie 合并插件按其 README 迁移，避免同时启用两份过滤中间件。

## 验证

Node 测试、Windows 启动器检查和浏览器检查均采用临时配置与本机模拟上游，不使用真实供应商凭据或额度。模型指纹仍为有限参考库的统计证据，保护机制及其局限见 [MODEL-GUARD.md](../MODEL-GUARD.md)。
