# v1.0.4 · Codex 过滤管理（服务 v29）

本版优化管理界面的配色和刷新反馈。公开版仍不预置供应商规则，历史过滤、Lite 兼容与模型保护默认关闭。

## 更新内容

- 采用灰白背景、白色卡片和靛蓝操作按钮，提供配套深色主题。右上角月亮 / 太阳按钮可切换，选择保存在当前浏览器并在刷新后保留。
- 模型异常保留红色、上游与样本问题保留黄色、样本匹配保留绿色，优化文字对比度、边框和窄屏布局。
- 修复「刷新列表」缺少操作反馈的问题：点击后显示旋转图标和「刷新中…」，结束后明确提示成功或失败；失败后可以再次尝试。
- 手动刷新会复用正在进行的自动刷新请求，避免重复读取或静默忽略点击。自动刷新保持安静；刷新列表只读取管理状态，不触发模型检测或修改供应商设置。
- 更新应用图标、README 和浅色 / 深色演示截图。截图仅包含虚构供应商和演示检测数据。

## 安装与升级

下载 `codex-filter-manager-v1.0.4-windows.zip`，解压后双击 `Start.bat`。首次需要运行时会下载并校验官方 Node.js，无需手动安装依赖。

已有安装请先运行旧目录 `Stop.bat`，备份自己的 `.runtime/`，覆盖源码后再运行 `Start.bat` 并重启 Codex。管理页面应显示 **v29**。升级保留本机规则与检测历史，旧通过记录不会在重启后恢复为有效信任。

## 验证与边界

覆盖刷新进度、重复点击、与自动刷新共用请求、成功 / 失败反馈及失败后恢复；检查浅色 / 深色主题、桌面与窄屏布局，并运行离线测试和 Windows 启动器检查，未调用真实供应商。

本版未修改历史过滤和模型检测算法。模型保护的统计结论与费用边界见 [MODEL-GUARD.md](https://github.com/unisong/codex-filter-manager/blob/v1.0.4/MODEL-GUARD.md)，算法和参考库来自 [ModelTrace（MIT）](https://github.com/xqy2006/ModelTrace)。
