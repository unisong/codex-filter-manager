# 更新记录

完整历史版本可从 [GitHub Releases](https://github.com/unisong/codex-filter-manager/releases) 获取。服务版本号单独记录在 `src/proxy.cjs`，产品版本号来自根目录 `package.json`。

## v1.0.8 / 服务 v34

- 统一 CC Switch 与 Magpie 工作台的页面层级：顶部只保留一次应用标题，页面内按“当前状态 → 主操作 → 配置列表 → 技术说明”组织内容。
- 历史过滤页把概览压缩为状态条，供应商表合并兼容规则与历史过滤开关，将低频的旧模型别名设置收纳到高级区域。
- 模型监测页减少重复状态横幅，把判定说明、费用与算法边界折叠；检测记录新增结果筛选并保持分页、滚动位置和 100 条上限。
- 供应商设置改为固定页头、可滚动正文和固定操作栏；模型保护与历史兼容分区保存。
- Magpie 工作台与原生设置页改用同一套暖棕/象牙配色和图标；定期间隔横幅只在模型监测与检测记录页、且确有任务运行时展示。
- 修正 Magpie 工作台和原生页面中过期的版本文案，版本从运行时或产品包读取。
- 启动器迁入 `scripts/windows/`，共享静态资源迁入 `web/assets/`，测试数据迁入 `tests/fixtures/`；根目录 `.bat` 仍是用户的一键入口。

## v1.0.7 / 服务 v33

- 修复历史 `web_search_call` 在旧 reasoning 被移除后缺少依赖的问题：把旧搜索记录转换为带说明的助手文字，保留可读查询、动作、状态和来源，同时去除服务器条目 ID。
- CC Switch 代理与 Magpie 历史钩子共用同一转换规则；普通工具配对、`call_id` 和后续结论保持不变。
- 新增本机诊断、脱敏报告、日志轮转和请求级决策说明。

## v1.0.6 / 服务 v32

- 统一工作台使用暖灰/铜色主题、单图标明暗切换和四分区导航。
- 模型监测优先展示最近实际请求，其次使用检测记录；无记录时才在本页选择模型。
- 增加诊断导出预览和更清楚的连接、过滤及上游故障区分。

## v1.0.5 / 服务 v31

- 增加 Magpie 原生历史过滤插件，同时保留 CC Switch 独立代理和模型保护。
- Magpie 模式不再依赖独立代理改写 Codex `base_url`；不同会话按请求中的供应商/模型前缀独立匹配规则。

## v1.0.4 / v1.0.3

- 改进模型保护的分区设置、请求前验证、失败冷却、锁定证据和记录页导航。
- 历史过滤、Lite 兼容与模型保护均改为按供应商显式开启，新安装不附带供应商规则。
