# 更新记录

完整历史版本可从 [GitHub Releases](https://github.com/unisong/codex-filter-manager/releases) 获取。服务版本号单独记录在 `src/proxy.cjs`，产品版本号来自根目录 `package.json`。

## v1.0.13 / 服务 v38

- 小体积发布包也至少展示约 1.1 秒加载动画；服务端拒绝安装或请求失败时立即收起动画并显示错误，不留下“一直加载”的假状态。
- 下载与安装完成后在页面顶部显示醒目的成功提示，并允许关闭。过期、低于当前版本或目标目录已不存在的旧完成状态不再重复显示。
- 设置页可自定义更新下载与暂存目录。保存前验证绝对路径、目录类型和写权限，自定义目录用于更新包、解压结果及回滚备份；恢复默认只恢复默认路径，不删除已有文件。
- 更新安装测试新增安装目录之外的暂存目录场景；两套工作台浏览器检查覆盖请求拒绝后的恢复、快速下载动画和成功横幅。
- 修复 Magpie 工作台将结构化接口错误显示为 `[object Object]` 的问题，现在会呈现服务端返回的具体中文说明。
- GitHub Actions 更新到当前稳定版本，消除旧版 Action 的 Node.js 20 弃用提示。

## v1.0.12 / 服务 v37

- 更新版本按语义版本从新到旧排列，首项标记「最新」；切换版本说明时回到顶部，阅读过程中状态刷新不重置滚动位置。
- Magpie 工作台首次打开或刷新后默认进入「历史过滤」；导航高亮、页面标题和可见内容同步，只有进入模型监测且无可用模型时才展示手动选择。
- 两套工作台显示实际下载字节数、总大小和百分比进度条；下载时每 500 毫秒刷新，页面重开后继续显示进度。解压与安装准备阶段显示「进行中」，不把下载 100% 当成安装完成。
- 保留本机下载、SHA-256 校验及独立目录准备流程。浏览器原生下载适合作为手动备用，不替代现有更新链路。
- 增加乱序版本、跨位版本号、分段下载、刷新页面恢复进度和准备阶段的离线回归；历史过滤与模型检测算法不变。

## v1.0.11 / 服务 v36

- 修复 Windows 更新助手采用 detached 启动时可能直接退出、不执行安装的问题。现在由短时 PowerShell 引导进程通过 `Start-Process -WindowStyle Hidden` 启动独立助手，并确认启动结果；过滤进程退出后助手仍可完成安装。
- 更新状态文件改为原子替换，避免轮询时出现短暂文件缺失。
- 新增生产启动路径的离线回归，验证父进程退出、中文及空格路径；保留安装、失败恢复、路径穿越、校验失败与 Magpie 独立目录检查。
- 包含 v1.0.10 的间歇漏过滤修复、页面关闭与版本更新功能。建议使用本版。

## v1.0.10 / 服务 v35

- 修复 CC Switch 数据库短暂锁定时，规则读取失败被误当成“关闭过滤”而原样转发，造成旧会话间歇出现跨资源 400 的问题。锁冲突最多异步重试 3 次；仍无法读取时返回带本地请求编号的 503，不向上游发送未确认规则的请求。
- 上传完成后的二次规则检查使用相同保护；重试期间重新读取当前供应商，不复用旧供应商规则。原有主动关闭、未配置供应商与自动故障转移的行为保持不变。
- 诊断保留脱敏后的 SQLite 错误类别、规则读取重试与拒绝记录；管理页在恢复后仍保留本次运行的异常提示，支持直接打开诊断。
- 修复检查更新时向 GitHub 版本查询接口发送二进制下载标头而返回 HTTP 415；版本查询使用 JSON，发布附件继续使用二进制下载。
- 两套工作台右上角增加关闭按钮，确认后停止本工具对应服务；CC Switch 恢复 Codex 配置，Magpie 保留宿主及历史过滤。
- 设置页增加手动检查更新与版本选择。Windows 发布包支持校验下载、备份安装、自动重启及失败恢复；Magpie 支持下载并准备独立新版插件目录。
- 服务关闭时取消正在进行的检测，不改变评分、历史过滤、保护开关或已保存的锁定。
- 增加关闭与更新 API 的授权检查、安装失败恢复及两套页面的离线浏览器测试。

## v1.0.9 / 服务 v34

- 修复 Windows 冷启动时进程查询超时，导致 PID 被其他进程复用后，旧 `service.json` 仍阻止启动或停止的问题。现在先用快速查询比对进程启动时间，不再依赖可能超时的命令行查询。v1.0.8 标签的 CI 就是因此失败。
- 删除 Magpie 插件根目录下重复的历史钩子副本、过期的 `PROVENANCE.json`，以及 7 张未被文档引用、仍显示旧 v0.2.1 界面的截图；测试统一使用 `history/` 下的固定基线。
- 新增 `AGENTS.md` 记录目录与提交规则。`release:check` 增加根目录和插件目录白名单、测试文件位置检查，并按暂存内容校验共享副本与公开钩子，避免把本机 Magpie 生成的暂停规则提交进仓库。
- 过滤、检测和界面行为不变。
