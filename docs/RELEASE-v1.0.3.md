# v1.0.3 · Codex 过滤管理（服务 v28）

本版修复汇总指纹分可能掩盖单个明显异常样本的问题，并区分模型异常、上游失败和当前保护状态。公开版仍不预置供应商规则，历史过滤、Lite 兼容与模型保护默认关闭。

## 更新内容

- 使用未修改的 ModelTrace 评分器，同时检查三个独立样本和汇总结果。单样本强差异不再被平均结果覆盖为通过；完全重复的样本不能作为独立证据。
- 保存完成评分的数字证据，支持展开、复制和导出 JSON。导出不含供应商标识、路由、密钥或项目正文，便于使用同一组数字复核。
- 429、断流、超时和部分临时服务异常整次检测共享最多 3 次额外重试，保留有效样本，只重试当前题目。一次检测最终只增加一条记录；余额不足、权限错误、模型不支持、无效完整样本不重试。
- 优先读取完成响应的正文，修复空 `output_text`、空白或片段 delta 遮住完整数字样本的问题。仍要求完整完成事件与正确模型标识。
- 已完成的明显模型差异和样本冲突显示红色；403、网络错误、无效样本和不足以判定的结果显示黄色。历史样本匹配使用绿色；缓存到期或保护关闭不改写当次结论。
- 新增独立「自动保护」状态行，说明当前开关、缓存复用、重检或锁定状态；保留旧版检测记录并明确标注缺少逐样本证据。
- README、检测原理、安全说明和演示截图同步更新。

## 安装与升级

下载 `codex-filter-manager-v1.0.3-windows.zip`，解压后双击 `Start.bat`。首次需要运行时会下载并校验官方 Node.js，无需手动安装依赖。

已有安装请先运行旧目录 `Stop.bat`，备份自己的 `.runtime/`，覆盖源码后再运行 `Start.bat` 并重启 Codex。管理页面应显示 **v28**。升级保留本机规则与历史，旧通过记录不会在重启后恢复为有效信任。

## 判定与费用边界

两轮汇总均达到强差异阈值且指向同一替代候选时，才新增持久锁定。红色异常不一定已经持久锁定；保护开启时，无法验证同样不放行，关闭时只展示结果。空回答、403 或断流本身不能证明模型降智。

通常 3 个探针，含复核最多 6 个；共享重试最多增加 3 次尝试，均可能计费。检测比较统计指纹，不证明模型身份、推理能力或实际项目请求一定使用同一后端。完整规则见 [MODEL-GUARD.md](https://github.com/unisong/codex-filter-manager/blob/v1.0.3/MODEL-GUARD.md)，算法与参考库来自 [ModelTrace（MIT）](https://github.com/xqy2006/ModelTrace)。

验证使用本机模拟 HTTP、临时数据库和合成数字样本，覆盖检测、传输、持久化、浏览器界面及 Windows 启动器；未调用真实供应商。
