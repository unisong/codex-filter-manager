# v1.0.7 · 历史搜索兼容修复（服务 v33）

- 修复过滤旧推理后，历史 `web_search_call` 仍依赖原 `reasoning` 而导致对话或压缩总结中断的问题。开启历史过滤时，旧搜索调用转为带标记的普通助手文字，保留已记录的查询、动作、状态及来源，去除服务器条目 ID 和内部回合元数据。
- 保留后续搜索结论、引用、普通工具参数与结果及 `call_id` 配对，不重新搜索或补造结果。CC Switch 代理与附带 Magpie 钩子使用相同处理逻辑；Magpie 合并插件同步发布 v0.2.1。
- 整理源码目录：服务在 `src/`、页面在 `web/`、测试在 `tests/`、开发工具在 `scripts/`，根目录 `filter.cjs` 与一键入口继续可用，默认运行数据仍在 `.runtime/`。
- 精简 README，将兼容选项原理与详细排障移至独立文档。

## 更新与使用

停止旧服务，备份 `.runtime/`，将新包的公开文件覆盖到原安装目录并运行 `Start.bat`，核对页面服务版本 **v33**。保留自己的规则与检测数据；新安装默认不启用过滤或保护。仅为需要兼容的供应商开启历史过滤，通常保留「新响应的加密内容请求」。

本修复处理完整明文历史的重放，不解密密文、不改写会话文件。不可迁移的加密压缩块、服务器引用及 `/responses/compact` 仍明确拒绝。Magpie 模式保持 Codex 原接入地址，避免重复安装两种过滤入口。

验证覆盖 Node 离线回归、本机模拟上游、Windows 启动器与浏览器交互；不使用真实供应商凭据或额度。
